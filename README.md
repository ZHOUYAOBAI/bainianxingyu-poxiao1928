# 《百年星语·破晓 1928》· 音乐剧数字剧本

云南民族大学 马笛团队原创红色音乐剧《百年星语·破晓 1928》的网页版数字剧本。

- **内容依据**：`《百年星语·破晓1928》v15（中稿）.docx`（2025 年 11 月中稿）
- **体裁**：音乐剧（本版为缩减成音乐剧的版本，与歌剧版分属两份稿件）
- **纯静态**：无框架、无依赖、不联网、不埋点。双击 `index.html` 即可阅读
- **四份底稿**：正文与分曲表取自 `《百年星语·破晓1928》v15（中稿）.docx`；第 04 / 10 两章取自作者另行提供的 `剧.docx`（分幕导览 + 创作意义）；第 01 章「创作缘起」由作者于 2026-11 直接提供，原文照录；第 02 章「试听」的 5 段 demo 录音由剧方提供

## 本地运行

```bash
cd 破晓1928_音乐剧_数字剧本站
python3 -m http.server 8899          # 然后打开 http://127.0.0.1:8899/
```

直接双击 `index.html`（`file://`）功能完全一致，脚本均为本地相对路径。

## 交互

- **幕导航**：随滚动高亮当前幕；分曲表点击跳转并高亮该曲
- **全文检索**：检索框实时高亮 `<mark>`，显示命中处数与所在段落数
- **角色高亮**：点人物表中的角色名，正文中该角色的全部台词与唱段高亮
- **字号**：A− / A+，16–26px，localStorage 持久化
- **唱段折叠**：单曲收起／展开，或一键「全部收起／展开」
- **阅读进度条**、**移动端抽屉菜单**、**打印样式**（自动隐藏导航与控件）

## 视觉

**亮色党政红主题**：暖米白纸面打底，大面积正红作为唯一主色，金线只作点缀，全站不使用暗底压暗的处理。

- **主色**：`--red:#c8102e`（党政红）· `--red-2:#a30f23` · `--red-3:#e0313f` · `--gold:#c9a227`
- **纸面**：`#fffdfa → #f9eadc` 暖米白渐变，卡片与表格白底
- **团队署名**：封面左上方金色描边红色绶带 + ★ 徽记 + 燕尾下摆，带一道 7 秒循环的高光扫过
- **封面马灯**：内联 SVG 重绘的 3D 煤油马灯（320×440）。造型依据作者提供的「华昌」煤油灯照片还原——弯折铁丝提梁与右端卷钩、黄铜通气帽与法兰、漆红 U 形铁架立柱、圆筒玻璃罩内的交叉护丝与 X 形铁丝、油壶旋钮与侧加油盖、落地投影与暖黄光晕；灯焰独立闪烁，整灯缓慢摆动
- **正文**：衬线体、行末小圆点标角色；检索高亮 / 声部筛选 / 进度条均为党政红

### 排版性处理（均已在页脚「编者注」标明）

1. 原稿「〔调度〕枪响。「砰！……」）（歌声骤止。）……」一处连写，本页按节拍拆为四条调度，文字未增删。
2. 原稿分曲表无「时长」一列，本页该列取自正文各曲的曲属性行（26 首有）。
3. 原稿分曲表中 No.18、20、23、24、27 的速度为半截写法（如「Adagio ♩=56→」），本页采用正文完整写法。
4. 原稿封面题「三幕十四场（暂定）」，正文可检索场号为 11 个（场 1—场 10，另含场 7B），二者并存。
5. 原稿封面署名「云南民大学院马笛团队原创红色音乐剧」中「云南民大学院」为笔误，本页据作者口述正作「云南民族大学 马笛团队原创红色音乐剧」，其余文字未动。
6. 第 03 节「分幕导览」与第 09 节「创作意义」取自作者另行提供的《剧.docx》。导览为音乐剧 14 场版（含终场共 15 场）的场次与音乐设计，与正文 v15 的 11 个插叙式场号、28 首分曲表属不同稿次，两套编号并存；导览中出现的《一盏灯》《等一颗星》《三圈线》《天亮之前》等唱段名属该稿，正文分曲表以 v15 为准。
7. 第 01 节「创作缘起」由作者于 2026 年 11 月直接提供，逐字照录。该节的「2026 年启动创作、2027 年 3 月定稿并排练、年内首演」指项目立项与排演时间表，与封面「2025 年 11 月中稿」的版本标记并存（二者所指不同，不冲突）。原封面题词「站在广场正中央 这里属我最亮」（No.1《追光》）按作者要求从封面移下，该句仍完整保留在正文该曲唱词中。
8. 第 02 节「试听」为创作阶段 demo 录音（非最终录音版），由剧方提供：追光、凝聚、血绢誓、起来全世界受苦的人，以及尚未定稿的新作《共和国的星辉》。前四段的唱词直接从正文按曲号抽取，与正文逐字一致；第 5 段歌词照录剧方提供版本，暂列末位。demo 仅供汇报试听，未获剧方书面授权请勿转载或二次上传。
9. 第 01 节所配查尼皮会址三图为公开报道图片，仅作场景示意，非剧照、非文物，页脚已逐张注明来源与授权。

除以上九项外，全文未作任何改写、增补或删节；原文中重复出现的唱词行（如 No.3「八个人里 四个连自己的名字都写不全」原稿连写两遍）亦按原样保留。
